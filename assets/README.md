# Logos

احتفظي باللوجوهات الأصلية الموجودة في مشروعك. لا تمسحي مجلد assets عند التحديث.
نسخة التحديث لا تحتوي على صور اللوجوهات الأصلية، وتستخدم الملفات الموجودة عندك بهذه الأسماء:

- `logo1.png`
- `logo2.png`
- `logo3.png`

اللوجوهات الموجودة تظهر في التطبيق وفي رأس ملف PDF، مع الحفاظ على أبعادها.
غياب أي لوجو لا يوقف التسجيل أو إنشاء الفاتورة.
مجلد fonts المرفق يدعم ظهور الأسماء العربية في PDF، ومعه ترخيص الخط.
