# Logos

مجلد `assets` في هذه النسخة يحتوي على اللوجوهات والخطوط المطلوبة. ارفعيه كاملًا مع باقي ملفات المشروع، ولا تمسحي محتوياته عند التحديث.

- `logo1.png`
- `logo2.png`
- `logo3.png`

اللوجوهات تظهر في التطبيق وفي رأس ملف PDF، مع الحفاظ على أبعادها.
غياب أي لوجو لا يوقف التسجيل أو إنشاء الفاتورة.
مجلد fonts المرفق يدعم ظهور الأسماء العربية في PDF، ومعه ترخيص الخط.
