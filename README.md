# 23rd ITKF Championship - Hotel Booking

نسخة كاملة ومعدلة من تطبيق حجز الفنادق، مع الحفاظ على الهيدر الأبيض والحد الأحمر وثلاثة لوجوهات والتنقل الحر بين الصفحات.

## أهم التعديلات

- تاريخ دخول وتاريخ خروج، وعدد الليالي يُحسب تلقائيًا.
- اليورو هو العملة الأساسية، والدولار والجنيه قيم تحويلية فقط.
- 9 فنادق بكل أسعار وخطط الوجبات الموجودة في الكتيب الرسمي.
- المواصلات: Limousine، Hiace Bus، Coaster Bus، 33-Seat Bus، 50-Seat Bus.
- أسماء المواصلات بالإنجليزية، ولكل عربية سعر فرد مستقل باليورو.
- أسعار المواصلات محفوظة داخل `config.py`، ولكل عربية سعر فرد مستقل باليورو.
- الجنسية Drop-down موحدة لكل الدول لمنع اختلاف الكتابة والتكرار.
- رقم الهاتف يُراجع حسب دولة الجنسية ويحفظ بصيغة دولية مثل `+201...`.
- التطبيق مثبت على Light Mode.
- حفظ آمن في Google Sheets مع Booking ID فريد وإعادة محاولات بدون تكرار الصفوف.
- حفظ صور الباسبور والصور الشخصية في Google Drive، والشيت يخزن الرابط ومعرّف الملف فقط.
- لا تظهر رسالة نجاح إلا بعد تأكيد جوجل أن صف التسجيل تم حفظه.
- إنشاء Invoice PDF محمي ضد التعديل بعد التأكيد، برقم فاتورة وكود تحقق فريدين.
- حفظ الفاتورة في Drive، وتسجيل رقمها وكود التحقق وبصمة SHA-256 في تبويبي `Bookings` و`Invoices`، ثم إرسالها للإيميل.
- حفظ حالة إرسال الإيميل وأي خطأ داخل الشيت، مع إعادة محاولة تلقائية اختيارية.
- في حالة فشل رفع صورة بعد حفظ الصف، يظل التسجيل موجودًا بحالة واضحة للمراجعة.

## تشغيل التطبيق

1. ارفعي كل ملفات هذا المجلد إلى جذر Repository في GitHub.
2. ضعي اللوجوهات داخل مجلد `assets` بالأسماء `logo1.png` و`logo2.png` و`logo3.png`.
3. في Streamlit Cloud اختاري `app.py` كملف التشغيل.
4. يثبت Streamlit المكتبات تلقائيًا من `requirements.txt`.

## ربط Google Sheets وGoogle Drive

### 1. إنشاء الشيت والفولدر

1. أنشئي Google Sheet جديدًا واتركيه فارغًا؛ السكربت ينشئ عناوين الأعمدة تلقائيًا.
2. من رابط الشيت انسخي الجزء الموجود بين `/d/` و`/edit`؛ هذا هو `SPREADSHEET_ID`.
3. أنشئي فولدر في Google Drive لحفظ الصور.
4. من رابط الفولدر انسخي الجزء بعد `/folders/`؛ هذا هو `DRIVE_FOLDER_ID`.

### 2. إعداد Apps Script

1. افتحي [Google Apps Script](https://script.google.com/) وأنشئي مشروعًا جديدًا.
2. احذفي الكود الافتراضي والصقي محتوى `google_apps_script.gs`.
3. من **Project Settings > Script Properties** أضيفي:
   - `SPREADSHEET_ID`: معرّف الشيت.
   - `DRIVE_FOLDER_ID`: معرّف فولدر الصور.
   - `BOOKING_API_TOKEN`: كلمة سر طويلة وعشوائية من اختيارك.
   - `COMPANY_NAME`: `Egyptian Traditional Karate Federation` (اختياري).
   - `INVOICE_FOLDER_ID`: فولدر منفصل للفواتير (اختياري؛ لو تركتيه فارغًا تُحفظ مع الصور).
4. اختاري **Deploy > New deployment > Web app**.
5. اختاري **Execute as: Me** و**Who has access: Anyone** ثم Deploy.
6. انسخي رابط Web app المنتهي بـ `/exec`.
7. من محرر Apps Script اختاري الدالة `installHourlyEmailRetryTrigger` وشغّليها مرة واحدة؛
   ده ينشئ محاولة كل ساعة للفواتير التي حُفظت لكن تعذر إرسالها.

### 3. إعداد Streamlit Secrets

في Streamlit Cloud افتحي **App Settings > Secrets** وأضيفي:

```toml
GOOGLE_APPS_SCRIPT_URL = "رابط_Web_App_المنتهي_بـ_exec"
BOOKING_API_TOKEN = "نفس_التوكن_الموجود_في_Script_Properties"
```

لا تضعي التوكن داخل `app.py` أو `config.py`، ولا ترفعي ملف `secrets.toml` الحقيقي إلى GitHub.

## إدخال أسعار المواصلات لاحقًا داخل الكود

افتحي `config.py` وعدلي قيمة `price_per_person_eur` أمام كل عربية في قسم
`TRANSPORTATION`. مثال بعد وصول سعر الفرد النهائي:

```python
TRANSPORTATION = {
    "Limousine": {"price_per_person_eur": 25.0},
    "Hiace Bus": {"price_per_person_eur": 18.0},
    "Coaster Bus": {"price_per_person_eur": 15.0},
    "33-Seat Bus": {"price_per_person_eur": 12.0},
    "50-Seat Bus": {"price_per_person_eur": 10.0},
}
```

التطبيق يحسب تلقائيًا:

`Transportation Total = Price Per Person EUR × Number of Persons`

لو السعر `None` تظهر `Price pending` ولا يسمح التطبيق بإصدار فاتورة خاطئة. بعد وضع الأسعار
ارفعي نسخة الكود المحدثة على GitHub ليعاد نشر التطبيق. لا تحتاجين إلى تعديل Apps Script أو Google Sheet.

سعر المواصلات المرسل للباك إند يكون موقّعًا بالتوكن، لذلك لا يقبل Apps Script تغيير السعر من الطلب.

## تغيير أسعار أخرى لاحقًا

- سعر الصرف: عدلي `CURRENCY_RATES` في `config.py`، والقيمتان تعنيان قيمة 1 يورو بالدولار وبالجنيه.
- الفنادق: عدلي الرقم داخل `HOTELS > اسم الفندق > rates > خطة الوجبات > نوع الغرفة`.

## ملاحظة مهمة عن إرسال 5000 فاتورة

Google Apps Script يستخدم `MailApp`، ولذلك يخضع للحد اليومي للإرسال في حساب Google.
النظام يسجل أي رسالة لم تُرسل ويعيد المحاولة، لكنه لا يستطيع تجاوز حد Gmail اليومي. إذا كان متوقعًا
إرسال آلاف الفواتير في يوم واحد، استخدمي خدمة بريد مخصصة مثل SendGrid أو Amazon SES بدل Gmail.

## اختبار قبل استقبال التسجيلات

1. افتحي رابط Apps Script في المتصفح؛ يجب أن تظهري استجابة فيها `ok: true`.
2. نفذي حجزًا تجريبيًا كاملًا مع صورة باسبور.
3. تأكدي أن الصف ظهر مرة واحدة في تبويب `Bookings`.
4. تأكدي أن الصور ظهرت في فولدر Drive وأن روابطها موجودة في الشيت.
5. تأكدي أن الفاتورة PDF وصلت للإيميل، ورقم الفاتورة وكود التحقق وبصمة SHA-256 موجودة في الشيت.
6. اضغطي إعادة المحاولة لنفس الحجز فقط عند ظهور فشل؛ نفس Booking ID يمنع إنشاء صف مكرر.
